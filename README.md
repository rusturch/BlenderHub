# Blender Hub

Blender Hub is a  launcher for Blender. Install and manage any number of Blender versions, browse your `.blend` projects, manage add-ons across every version at once, and keep your settings in sync — all from one app.

> ⚠️ Early access — actively developed. Some flows are not yet verified against live installs.

## Features

- **Versions** — install daily, beta, alpha, experimental and PR builds plus the full stable archive; downloads are sha256-verified. Launch, reveal, and uninstall from one list.
- **Projects** — scan folders for `.blend` files with thumbnails and the version each file was made in; open a project in its native version or any other you have installed.
- **Add-ons** — an "add-on × Blender version" matrix that reads state without launching Blender. Enable, disable, install, remove, and switch versions in a single Apply. Install from a built-in file library, extensions.blender.org, or Superhive.
- **Sync** — copy preferences, startup file, bookmarks, presets, scripts and datafiles between versions, with automatic backups and restore.
- **Portable** — all state lives in a `data/` folder next to the launcher. Move the folder (or point it at a cloud drive) and everything comes with it.
- Self-updating, tray integration, English / Russian interface.

**Platforms:** Windows today; macOS and Linux planned.
